# 跨端基础能力验证

## 目的

验证正式 MVP 开始前的高风险基础能力，不包含书架、翻页视觉和正式 UI。

## 验证顺序

1. 电脑 Chrome
2. GitHub Pages 临时 HTTPS 地址
3. iPhone 15 + 最新公开 iOS Safari
4. 小红书开发者工具模拟器
5. 小红书真机预览

## 验证项目

- Canvas 2D：单指拖动元素、双指移动画布、双指缩放 50%～200%。
- 文字：Canvas 页面上叠加原生输入框，双击进入输入，保存后恢复。
- IndexedDB：保存和恢复页面 JSON、素材索引和 PNG Blob。
- PWA：首次联网缓存应用资源，刷新后可离线打开。
- 图片：读取相册图片、缩放最长边 1024、生成 PNG。
- 小红书：Canvas 2D 绘制、触摸事件、图片读取和本地文件保存。

## 通过标准

- Chrome 和 iPhone 15 Safari 的拖动、缩放、文字输入、IndexedDB 全部可用。
- PWA 首次联网后断网刷新仍能打开测试页。
- 小红书模拟器和真机能完成基础 Canvas 操作及本地图片保存。
- 任一平台若存在阻断性差异，先记录平台适配方案，再进入正式 UI 开发。
